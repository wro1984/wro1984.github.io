# HUB dos apps

Tela inicial dos apps do Centro de Operações no celular (PWA): a pessoa entra uma vez, com matrícula e chave,
e vê os atalhos dos apps liberados para ela.

- Publicado pelo GitHub Pages na raiz de <https://wro1984.github.io/>, para que o app instalado abranja todos
  os apps (`/CO_PROB/`, `/CO_Painel/` e os próximos).
- O repositório é **público**. A lista de apps de cada pessoa chega no `hub.json`, **cifrada** com a chave dela,
  publicado pelo MAPI (Comunicação → HUB dos apps). Nunca edite o `hub.json` à mão.
- Acessos, perfis e catálogo de apps são geridos no MAPI, não aqui.
