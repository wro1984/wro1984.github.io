# HUB dos apps

Tela inicial dos apps do Centro de Operações no celular (PWA): a pessoa entra uma vez, com matrícula e chave,
e vê os atalhos dos apps liberados para ela.

- Endereço: <https://wro1984.github.io/> (raiz, para que o app instalado abranja todos os apps).
- Instalar: Android (Chrome) → menu ⋮ → **Instalar app**; iPhone (Safari) → Compartilhar → **Adicionar à Tela de Início**.
- O repositório é **público**. A lista de apps de cada pessoa chega no `hub.json`, **cifrada** com a chave dela, publicado
  pelo MAPI (Comunicação → HUB dos apps). Acessos, perfis e catálogo são geridos no MAPI.
- Para mexer no código, leia o `CLAUDE.md`.
